## 먼저, 짧게 정리하면

**puzzleleaf의 기술블로그**입니다. 개발 중 만나는 문제와 배운 내용을 정리합니다. 기존 글은 삭제하고 새로 작성하는 글부터 공개합니다.

## 어떤 기록을 남길까요?

문제를 해결한 코드만 남기면 나중에 왜 그렇게 고쳤는지 잊기 쉽습니다. 이 블로그에서는 다음 내용을 함께 담으려고 합니다.

- **문제와 환경**: 어떤 조건에서 무엇이 발생했는지
- **확인한 원인**: 관찰한 사실과 아직 확인하지 못한 가설
- **해결과 검증**: 어떤 변경을 했고 결과를 어떻게 확인했는지
- **참고 자료**: 공식 문서와 추가로 읽을 수 있는 자료

직접 얻은 결과와 참고한 내용을 구분하고, 변경이 생기면 글에 수정일을 남깁니다.

## 이 블로그는 어떻게 만들어졌나요?

글은 Markdown 파일로 관리하고, Astro가 배포할 때 HTML로 만듭니다. 글을 읽는 데 JavaScript 실행이 필요하지 않습니다. GitHub Actions에서 검사와 빌드를 거쳐 GitHub Pages로 배포하도록 구성했습니다.

검색과 탐색을 위해 태그별 페이지, RSS, 사이트맵을 제공하고, 글에는 작성자와 게시일을 표시합니다. 검색 서비스가 페이지 내용을 이해할 수 있도록 구조화 데이터도 함께 생성합니다.

이 구성만으로 검색 순위나 AI 검색 인용이 보장되지는 않습니다. 실제로 도움이 되는 구체적인 경험을 꾸준히 기록하는 것이 먼저입니다.

## 새로운 기록을 만나는 방법

홈에서 최근 글을 둘러보거나, 태그를 눌러 주제별로 읽을 수 있습니다. 상단 검색 버튼 또는 `Ctrl + K`로 글을 찾을 수 있고, RSS 리더로 새 글을 구독할 수 있습니다.

함께 표시된 **샘플** 글은 작성 형식을 설명하기 위한 예제이며 검색 색인 대상에서 제외됩니다.
