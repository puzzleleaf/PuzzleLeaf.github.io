## 이 글에서 다루는 것

이 글은 **트러블슈팅 기록을 위한 샘플**입니다. 실제 장애 사례가 아니라 문제를 정리하는 방법을 설명합니다. 자신의 문제와 확인 결과로 바꾸어 사용하세요.

## 관찰과 추측 나누기

"서버가 느리다"보다 "같은 요청을 보냈을 때 어떤 조건에서 응답이 지연되는지"를 적으면 확인할 수 있는 범위가 분명해집니다.

| 구분 | 기록할 내용 |
| --- | --- |
| 관찰 | 직접 확인한 오류 메시지, 로그, 입력 |
| 가설 | 원인이라고 생각하지만 검증하지 않은 내용 |
| 확인 방법 | 가설을 지지하거나 배제할 수 있는 실험 |

## 재현 순서 줄이기

1. 문제가 나타나는 환경과 버전을 적습니다.
2. 재현에 필요한 입력과 설정만 남깁니다.
3. 같은 순서로 반복했을 때 같은 결과인지 확인합니다.
4. 정상 동작하는 경우와 다른 점을 찾습니다.

오류 메시지에 계정 정보나 토큰이 포함되어 있다면 공개 글에 넣기 전에 제거합니다.

## 한 번에 하나씩 확인하기

여러 설정을 동시에 바꾸면 어떤 변경이 효과가 있었는지 판단하기 어렵습니다. 가설마다 확인 방법과 결과를 묶어 기록합니다.

```text
가설:
확인한 방법:
관찰한 결과:
다음으로 확인할 것:
```

## 해결 뒤에 남길 것

문제를 재현했던 순서로 다시 확인하고, 변경이 다른 동작에 영향을 주는지도 살펴봅니다. 해결되지 않은 조건과 추가로 확인할 부분을 남기면 다음 기록을 이어가기 쉽습니다.
